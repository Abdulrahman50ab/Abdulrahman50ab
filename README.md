## Executive Overview

I am a Software Engineer and Founder/Lead Architect at **Abaixo** ([abaixo.online](https://abaixo.online)), focused on building resilient, high-throughput software across three core engineering domains:
1. **Cloud-Native Web & SaaS Architecture:** Engineering production-grade platforms with Next.js (App Router), TypeScript, React, Tailwind CSS, Lenis kinetic physics, and serverless cloud runtimes.
2. **Cross-Platform Mobile & Desktop Systems:** Architecting reactive, 60fps applications across Android, iOS, Windows, and macOS utilizing Flutter, Dart, Electron, and local-first encrypted persistence.
3. **Agentic AI & Low-Latency Audio OS:** Engineering real-time speech-to-text engines (sub-180ms Groq LPUs, WASAPI streams, Win32 hardware cursor injection), multi-agent orchestration (LangGraph), Dynamic RAG (pgvector), and computer vision pipelines (OpenCV).

#### FlowVoice AI — Windows Voice Dictation & Roman Urdu Translation OS
- **Overview:** Native Windows 10/11 desktop background AI voice dictation utility with sub-180ms latency, native Roman Urdu transcription, and Bring Your Own Key (BYOK) privacy.
- **Architecture & Technical Highlights:**
  - 16kHz WASAPI audio stream capture pipeline with a 28Hz subsonic DC rumble filter.
  - Direct ultra-fast routing to Groq LPU Whisper Large v3 models, achieving sub-180ms median voice-to-cursor latency.
  - Native Win32 hardware scan-code injection (`SendInput` with `AttachThreadInput` coupling) allowing direct cursor text insertion across any active window without losing focus.
  - Zero-telemetry BYOK architecture operating at $0 recurring costs.
- **Stack:** `Python` `Groq Whisper Large v3` `Win32 API` `PySide6` `WASAPI` `SoundDevice`
- **Links:** [Repository](https://github.com/Abdulrahman50ab/wisprflow) | [Live Product (flowvoice.abaixo.online)](https://flowvoice.abaixo.online)

#### RestoCloud POS — Restaurant Management & Kitchen OS
- **Overview:** Offline-first cloud POS and restaurant management ecosystem for dining rooms, cafes, and cloud kitchens with Kitchen Display (KDS) routing and real-time inventory deduction.
- **Architecture & Technical Highlights:**
  - Offline-first local storage and sync engine guaranteeing 100% continuous order punching during internet disconnects.
  - Real-time Kitchen Display System (KDS) bump bar station routing accelerating kitchen turnaround by 45%.
  - Gram-accurate Bill of Materials (BOM) recipe inventory deductions upon ticket punch.
  - ESC/POS thermal receipt printing and shift cash drawer reconciliation.
- **Stack:** `React` `TypeScript` `Tailwind CSS` `Cloud Firestore` `Offline Storage` `ESC/POS` `Vite`
- **Links:** [Repository](https://github.com/Abdulrahman50ab/Pos-Restaurant) | [Live Demo (resto.abaixo.online)](https://resto.abaixo.online)

## Architectural Principles & Engineering Standards

- **Clean Layered Architecture:** Strict separation between Presentation, Domain/Business Logic, and Data Persistence layers across mobile and web systems.
- **Offline-First Resilience:** Local encryption and synchronization queues ensure uninterrupted functionality during network interruptions.
- **Type Safety & Reliability:** Zero implicit any policies across TypeScript and complete null safety across Dart and Python type annotations.
- **Vector Iconography & Ergonomic UI:** Strict adherence to 8pt spatial grid geometry, thumb-zone primary interactions, tabular numeric scales, and 100% vector iconography.
- **Zero-Trust Security:** Role-based access control (RBAC), parameterized queries (SQL injection prevention), and cryptographic token verification on all public endpoints.
