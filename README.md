## Architectural Principles & Engineering Standards

- **Clean Layered Architecture:** Strict separation between Presentation, Domain/Business Logic, and Data Persistence layers across mobile and web systems.
- **Offline-First Resilience:** Local encryption and synchronization queues ensure uninterrupted functionality during network interruptions.
- **Type Safety & Reliability:** Zero implicit any policies across TypeScript and complete null safety across Dart and Python type annotations.
- **Vector Iconography & Ergonomic UI:** Strict adherence to 8pt spatial grid geometry, thumb-zone primary interactions, tabular numeric scales, and 100% vector iconography.
- **Zero-Trust Security:** Role-based access control (RBAC), parameterized queries (SQL injection prevention), and cryptographic token verification on all public endpoints.
